# Workspace: rationale and sources

Maintainer guide for the [workspace skill](SKILL.md). Executable procedures cover the native versus standalone [browser](references/browser.md) boundary and the development [sandbox](references/sandbox.md).

Workspace panels display state owned elsewhere. Standalone Chromium does not share native desktop tabs, cookies or login state. A browser screenshot is not native desktop acceptance. Development tools belong in the sandbox image, not on the host.

The formerly bundled generative Canvas integration and its authoring guidance were removed at the operator's request. Historical implementation evidence remains in repository history.
